# Media notes

The project cover is a generated brand illustration of a paper helicopter, created with the built-in image-generation tool. It is not experimental evidence. The three trial videos in dist/media are the creator's actual recordings, with no generated frames.

The revised demonstration narration uses Kokoro-82M-v1.0 with the generic af_heart voice at speed 1.03. No person's voice was cloned. English captions are prepared separately and aligned to the narration. Kokoro weights and the inference library use Apache 2.0 licenses; model weights are not included in the application.

References:
- https://github.com/hexgrad/kokoro
- https://huggingface.co/onnx-community/Kokoro-82M-v1.0-ONNX

The revised presentation follows: problem, how we solve it, what we built, results. Real Twitch verification captures retain their original context and are separate from the practice walkthrough.
